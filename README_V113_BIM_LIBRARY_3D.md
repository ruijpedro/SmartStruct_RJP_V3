# SmartStruct RJP V113 — Biblioteca BIM + 3D

- Biblioteca BIM estrutural com elementos paramétricos reutilizáveis.
- Inserção de pilares, vigas, lajes, sapatas, ensoleiramentos, estacas, paredes, aço, madeira e contenção.
- Visualizador BIM 3D volumétrico com seleção de objetos, rotação, eixos e terreno.
- Modelo de Edifício com representação 3D paramétrica.
- Geotecnia com cena 3D conceptual para reconhecimento, capacidade, assentamentos e nível freático.
- Taludes com representação 3D, superfície potencial de rotura e reforços.
- Mantém IFC/openBIM e ligação aos módulos de cálculo.
